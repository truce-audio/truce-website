# Reiss Vibrato

<img src="/screenshots/reiss-mcpherson/vibrato.png" class="screenshot-hero" width="415" height="113" alt="Reiss Vibrato">

LFO-modulated short delay - produces a periodic pitch wobble.

Source: [`reiss-mcpherson-vibrato/`](https://github.com/truce-audio/reiss-mcpherson-effects/tree/main/plugins/reiss-mcpherson-vibrato).

## What it demonstrates

- A short delay line whose read offset is driven by an LFO
- Switchable LFO waveform via `EnumParam`
- Switchable interpolation mode for the fractional read
