# Reiss Flanger

<img src="/screenshots/reiss-mcpherson/flanger.png" class="screenshot-hero" width="415" height="182" alt="Reiss Flanger">

Modulated short delay summed with the dry signal - the sweeping
comb-filter notches that produce the flanger sound.

Source: [`reiss-mcpherson-flanger/`](https://github.com/truce-audio/reiss-mcpherson-effects/tree/main/plugins/reiss-mcpherson-flanger).

## What it demonstrates

- LFO-modulated short delay summed with the dry input
- A feedback path
- Switchable LFO waveform via `EnumParam`
