# GUI Zoo (iced)

<img src="/screenshots/examples/gui-zoo-iced.png" class="screenshot-hero" width="350" height="450" alt="gui-zoo-iced plugin">

The widget reference rendered through `truce-iced`. Mirrors the
built-in [gui-zoo](./gui-zoo)'s param set so each truce-iced
widget counterpart is exercised against the same shape.

Source: [`examples/truce-example-gui-zoo-iced/`](https://github.com/truce-audio/truce/tree/main/examples/truce-example-gui-zoo-iced).

## What it demonstrates

- Iced counterparts of every built-in widget kind
- Iced `Column` / `Row` / `Container` composition
