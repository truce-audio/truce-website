# Reiss Distortion

<img src="/screenshots/reiss-mcpherson/distortion.png" class="screenshot-hero" width="346" height="113" alt="Reiss Distortion">

Five-shape waveshaper with input drive, output tone shelf, and
dry/wet mix.

Source: [`reiss-mcpherson-distortion/`](https://github.com/truce-audio/reiss-mcpherson-effects/tree/main/plugins/reiss-mcpherson-distortion).

## What it demonstrates

- Five waveshaping functions selected by `EnumParam`
- Input drive pre-shape and a tone shelf post-shape
- Dry/wet mix for parallel-style blending
