# GUI Zoo (egui)

<img src="/screenshots/examples/gui-zoo-egui.png" class="screenshot-hero" width="350" height="450" alt="gui-zoo-egui plugin">

The widget reference rendered through `truce-egui`. Mirrors the
built-in [gui-zoo](./gui-zoo)'s param set so each truce-egui
widget counterpart is exercised against the same shape.

Source: [`examples/truce-example-gui-zoo-egui/`](https://github.com/truce-audio/truce/tree/main/examples/truce-example-gui-zoo-egui).

## What it demonstrates

- Egui counterparts of every built-in widget kind
- Egui panel + grid composition for laying out the same widget set
