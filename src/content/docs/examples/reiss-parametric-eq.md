# Reiss Parametric EQ

<img src="/screenshots/reiss-mcpherson/parametric-eq.png" class="screenshot-hero" width="346" height="113" alt="Reiss Parametric EQ">

Single-band parametric EQ with seven filter shapes selectable at
runtime: low-pass, high-pass, band-pass, notch, low-shelf,
high-shelf, peaking.

Source: [`reiss-mcpherson-parametric-eq/`](https://github.com/truce-audio/reiss-mcpherson-effects/tree/main/plugins/reiss-mcpherson-parametric-eq).

## What it demonstrates

- Biquad coefficient generation for the seven filter shapes
- Mode switch via `EnumParam`
- Frequency / Q / gain controls shared across shapes
