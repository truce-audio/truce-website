# Reiss Pitch Shift

<img src="/screenshots/reiss-mcpherson/pitchshift.png" class="screenshot-hero" width="277" height="113" alt="Reiss Pitch Shift">

Phase-vocoder pitch shifter - shifts the input by a configurable
ratio while preserving the time scale.

Source: [`reiss-mcpherson-pitchshift/`](https://github.com/truce-audio/reiss-mcpherson-effects/tree/main/plugins/reiss-mcpherson-pitchshift).

## What it demonstrates

- An STFT-based phase vocoder with bin-shift resynthesis
- Phase-coherent reassembly for sustained tones
- Latency reporting for the analysis window
