# GUI Zoo (vizia)

<img src="/screenshots/examples/gui-zoo-vizia.png" class="screenshot-hero" width="302" height="460" alt="gui-zoo-vizia plugin">

The widget reference rendered through `truce-vizia`. Mirrors the
built-in [gui-zoo](./gui-zoo)'s param set so each truce-vizia
widget counterpart is exercised against the same shape.

Source: [`crates/truce-vizia/examples/truce-example-gui-zoo-vizia/`](https://github.com/truce-audio/truce/tree/main/crates/truce-vizia/examples/truce-example-gui-zoo-vizia).

## What it demonstrates

- Vizia counterparts of every built-in widget kind
- Vizia `HStack` / `VStack` / `ZStack` composition

Lives in the `truce-vizia` Cargo sub-workspace - see the [vizia
integration guide](../guide/gui/vizia). Desktop only.
