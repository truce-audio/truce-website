# Reiss Tremolo

<img src="/screenshots/reiss-mcpherson/tremolo.png" class="screenshot-hero" width="277" height="113" alt="Reiss Tremolo">

LFO amplitude modulation - the classic pulsing volume effect.

Source: [`reiss-mcpherson-tremolo/`](https://github.com/truce-audio/reiss-mcpherson-effects/tree/main/plugins/reiss-mcpherson-tremolo).

## What it demonstrates

- Input multiplied by a unipolar LFO scaled by a depth control
- Switchable LFO waveform via `EnumParam`
- A stereo phase offset on the LFO
