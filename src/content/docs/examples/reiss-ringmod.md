# Reiss Ring Modulator

<img src="/screenshots/reiss-mcpherson/ringmod.png" class="screenshot-hero" width="277" height="113" alt="Reiss Ring Mod">

Multiplies the input signal by a sine carrier, producing sum and
difference frequencies.

Source: [`reiss-mcpherson-ringmod/`](https://github.com/truce-audio/reiss-mcpherson-effects/tree/main/plugins/reiss-mcpherson-ringmod).

## What it demonstrates

- Sample-by-sample multiplication of input by a sine oscillator
- Log-scaled carrier frequency control
