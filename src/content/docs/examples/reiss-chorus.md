# Reiss Chorus

<img src="/screenshots/reiss-mcpherson/chorus.png" class="screenshot-hero" width="346" height="182" alt="Reiss Chorus">

Multi-voice chorus - several modulated delay lines summed in
parallel for an ensemble effect.

Source: [`reiss-mcpherson-chorus/`](https://github.com/truce-audio/reiss-mcpherson-effects/tree/main/plugins/reiss-mcpherson-chorus).

## What it demonstrates

- Several LFO-modulated delay voices summed in parallel
- A per-voice phase offset on the shared LFO
- Voice count as an `IntParam`
